متجر إلكتروني عربي (RTL) بواجهة عصرية فاخرة، متجاوب مع الهاتف أولاً، مع لوحة تحكم مخفية للإدارة.

## الواجهة الأمامية

- **شريط علوي**: اسم المتجر "شروة ستور" + أيقونة سلة تعرض عدد العناصر.
- **شريط أقسام أفقي قابل للتمرير**: الكل، إكسسوارات، عطور، عناية بالبشرة، هدايا رجالية، هدايا نسائية، مواد منزلية، كماليات السيارات، ساعات، أجهزة إلكترونية.
- **شبكة المنتجات**: صورة، اسم، فئة، السعر بالدينار العراقي (د.ع) مع فاصل آلاف، زر "إضافة للسلة".
- **سلة جانبية (Sidebar)**: زيادة/إنقاص الكمية، حذف منتج، المجموع الكلي. محفوظة محلياً حتى بعد إغلاق الصفحة.
- **إتمام الطلب**: نافذة تطلب الاسم، العنوان، رقم الهاتف → تُنشئ رسالة نصية بتفاصيل الطلب والمجموع وتفتح واتساب على الرقم +9647828638203.
- **التصميم**: خط عربي عصري، ألوان دافئة فاخرة (ذهبي/داكن) عبر رموز التصميم في styles.css، أيقونات Lucide.

## لوحة التحكم (مخفية)

- مسار غير معلن `/admin` مع تسجيل دخول (بريد + كلمة مرور) — لا يظهر أي رابط له في الواجهة.
- جدول منتجات مع إضافة/تعديل/حذف، رفع صور للمنتجات، اختيار الفئة، السعر، الوصف، حالة التوفر.
- يظهر المحتوى المضاف فوراً في المتجر.

## الخلفية (Lovable Cloud)

- تفعيل Lovable Cloud لتخزين المنتجات والصور وتسجيل دخول المدير — بدلاً من Local Storage، لتتمكن من الإضافة من أي جهاز.
- جدول `products` (اسم، فئة، سعر، صورة، وصف، متوفر) — قراءة عامة للجميع، والكتابة للمدراء فقط.
- جدول أدوار منفصل `user_roles` للتحقق من صلاحية المدير على الخادم (لا اعتماد على المتصفح).
- مخزن ملفات عام لصور المنتجات.
- بذر أولي لبضعة منتجات نموذجية لكل قسم حتى لا تكون الصفحة فارغة.

## تفاصيل تقنية

- مسارات TanStack: `/` (المتجر)، `/admin` (دخول + إدارة) مع بيانات ووصف SEO خاص لكل مسار.
- حالة السلة عبر React context + localStorage؛ لا حاجة لبوابة دفع.
- رابط واتساب: `https://wa.me/9647828638203?text=...` مع ترميز الرسالة.
- كل الألوان عبر رموز دلالية في `src/styles.css` (لا ألوان ثابتة داخل المكونات).

## الخطوة الأولى بعد الموافقة

تفعيل Lovable Cloud ثم إنشاء الجداول، بعدها بناء المتجر ولوحة التحكم. سأزوّدك بطريقة إنشاء حساب المدير بعد الانتهاء.
